# Банк задач ЕГЭ (FIPI Viewer)

Задачи открытого банка ФИПИ по профильной математике, разложенные по номерам ЕГЭ-2027:
поиск, фильтры, решения и подборки в PDF.

Один код работает в двух режимах:

| | **Редактор** (учитель, локально) | **Публичный сайт** (ученики) |
|---|---|---|
| Запуск | `python app.py` | `python freeze.py` → статические файлы |
| Решения | просмотр и редактирование | только просмотр, под спойлером |
| Служебная разметка (статус, причина, схема) | видна | скрыта |
| PDF | «Скачать PDF» (готовый файл через Chrome/Edge) | «PDF / печать» — браузер ученика сохраняет PDF сам |
| Сервер | Flask | не нужен (любой статический хостинг) |

Список, фильтры и печать работают в браузере по файлу `data/tasks.json`, поэтому
ученикам не нужен ни сервер, ни база данных. Ссылки с фильтрами
(`…/?number=9&type=Краткий+ответ`) можно отправлять ученикам.

## Редактор (локально)

```powershell
cd D:\fipi\fipi_gui
python -m pip install -r requirements.txt
python app.py
```

Открыть http://127.0.0.1:5000. Порт меняется через `$env:PORT="5055"`.

Другой файл с задачами: `$env:FIPI_DATA_FILE="D:\fipi\other.jsonl"` (по умолчанию `data/tasks.jsonl`).

## Решения

- `data/reference_solutions.json` — эталонные решения (только чтение);
- `data/solutions.json` — правки из редактора, перекрывают эталон.

Формат обоих файлов: `{"GUID": {"answer": "...", "solution": "..."}}`.
В тексте решения формулы пишутся в LaTeX: `$x^2$` в строке, `$$...$$` отдельной строкой;
пустая строка — новый абзац, `**жирный**`, строки с `- ` или `1. ` — список.
KaTeX лежит локально в `static/katex`, внешние CDN не нужны.

## Подборки и печать

- У каждой задачи есть галочка «В подборку». Подборка хранится в браузере
  (localStorage), панель внизу экрана: открыть, распечатать, получить код, открыть по коду.
- **Код подборки** (например `1G02-0S6D-A00R-R`) однозначно задаёт набор задач и их порядок
  и открывается на любом устройстве: через «Открыть по коду» или ссылкой `…/?set=КОД`.
  Внутри — постоянные номера задач из `data/task_ids.json` + контрольная сумма
  (опечатка в коде даёт ошибку, а не чужую подборку).
- `data/task_ids.json` **обязательно коммитить**: номер, выданный задаче, не должен
  меняться, иначе старые коды начнут открывать другие задачи. Новые задачи получают
  следующие номера автоматически при запуске `python app.py`.
- В печати: «решения», «ответы в конце» и «поле для решения» — клетка 5 мм:
  у задач с кратким ответом условие + клетка занимают полстраницы,
  у задач с развёрнутым ответом клетка — отдельный целый лист.

## Картинки

Берутся из `data/images`, а если такой папки нет — из `../fipi_dump/images`
(или из `FIPI_IMAGES_DIR`). В редакторе отсутствующий файл один раз пытаемся скачать
с ege.fipi.ru; если ФИПИ недоступен, повторные попытки откладываются на 10 минут.

Старый парсер пропускал картинки вида `ShowPictureQ("…", "")`. Докачать их:

```powershell
python fetch_images.py
```

## Публикация для учеников

### Сборка

```powershell
python freeze.py                # сайт в корне домена
python freeze.py --base fipi    # сайт по адресу https://<логин>.github.io/fipi/
python -m http.server 8000 --directory dist   # проверить: http://localhost:8000
```

Папку `dist/` можно выложить на любой статический хостинг.

### GitHub Pages (автоматически, бесплатно)

В корне репозитория (`D:\fipi`) лежит `.github/workflows/pages.yml`:
на каждый `git push` в `main` GitHub сам запускает `freeze.py` и публикует сайт.

1. Создать репозиторий на GitHub и запушить в него `D:\fipi`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Через 1–2 минуты сайт доступен по `https://<логин>.github.io/<репозиторий>/`.

Обновление решений: правишь в редакторе → меняется `data/solutions.json` →
`git commit` + `git push` → сайт пересобирается сам.
